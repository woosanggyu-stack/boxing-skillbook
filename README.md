# 혼자 하는 섀도복싱

완전 입문자가 장비 없이 혼자 보고 따라 하는 섀도복싱 스킬북 웹앱(PWA)입니다. 스탠스부터 풋워크, 기본 펀치, 방어, 콤비네이션까지 18장의 카드와 8주 프로그램이 들어간 라운드 타이머(종소리·10초 알림·콤비 콜아웃)가 있고, 한 번 열어 두면 인터넷 없이도 동작합니다.

- 바로 쓰기: https://woosanggyu-stack.github.io/boxing-skillbook/
- 아이폰: Safari로 열기 → 공유 → **홈 화면에 추가**
- 안드로이드: Chrome으로 열기 → 메뉴(⋮) → **홈 화면에 추가** (또는 **앱 설치**)

모든 방향 안내는 오소독스(왼발·왼손이 앞) 기준이고, 카드마다 사우스포 안내가 있습니다. 그림은 모두 직접 그린 단순 도식입니다.

## 로컬 실행

`실행하기.bat`을 더블클릭하거나 `python server.py 8640`을 실행한 뒤 http://localhost:8640 을 엽니다.

- 카드 내용·8주 프로그램·콤비 목록: `js/data.js`
- 그림: `js/figures.js`
- 라운드 타이머: `js/timer.js`
- 커리큘럼 기획: `curriculum.md`
- 아이콘 다시 만들기: `python tools/make_icons.py` (모양은 `icon.svg`와 같게 유지)

파일을 고친 뒤 배포할 때는 `sw.js`의 `CACHE` 버전을 올리면 설치된 앱의 오프라인 캐시가 새로 채워집니다.
